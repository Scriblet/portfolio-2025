# Issue: Mapa de Maturidade em IA: mapa visual + responsividade

Status: done

## Parent
PRD: `.scratch/04-secoes/mapa-maturidade-ia/PRD.md`

## What to build
Transformar a lista base em um mapa de maturidade visual: escada ou pirâmide que comunica progressão, com cor progressiva por camada, ícone MUI por nível e conexão visual entre as camadas. Garantir layout de 320px a 1920px sem overflow horizontal.

## Acceptance criteria
- [ ] Camadas exibidas como mapa progressivo (escada/pirâmide) com conexão visual entre níveis
- [ ] Cada camada tem ícone e cor progressiva coerentes com o nível
- [ ] Layout adapta-se de 320px a 1920px sem overflow horizontal
- [ ] Hierarquia tipográfica distinguível entre título, descrição e capacidades
- [ ] Nenhuma imagem pesada ou animação contínua
- [ ] Visual consistente com o design system escuro existente
